# فون زون | PhoneZone — متجر إلكتروني متكامل للهواتف الذكية والإلكترونيات

منصة تجارة إلكترونية متطورة وعصرية متخصصة في بيع الهواتف الذكية، الأجهزة اللوحية، الساعات الذكية، الشواحن، الإكسسوارات ووسائل الحماية، مبنية بأحدث معايير **Next.js 16 (App Router)** و **React 19** مع دعم بيئة التشغيل السريعة **Vinext (Vite + Cloudflare Workers)** ومصممة بالكامل باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL).

---

## 🌟 مميزات المشروع الرئيسية

### 1. تجربة مستخدم عربية فاخرة (Luxury Dark Theme + RTL)
- **تصميم متجاوب بالكامل**: واجهة عربية أنيقة بخط **Almarai** من Google Fonts وتنسيق كامل للعملات مع دعم تخصيص العملة وموضع الرمز.
- **هوية بصرية فخمة**: نمط داكن (Dark Emerald/Lime Aesthetic) مع شريط عاجل متحرك (Marquee Ticker)، بطاقات عروض Bento Grid، ومؤقت تنازلي لعروض اليوم المحدودة.
- **سلايدر رئيسي تفاعلي (Hero Slider)**: سلايدر ديناميكي بالكامل يدعم التحكم التلقائي واليدوي وربط الأزرار المباشرة.
- **معاينة سريعة للمنتجات (Quick View Modal)**: إمكانية استعراض تفاصيل المنتج واختيار الألوان وإضافته للسلة فوراً دون مغادرة الصفحة.

### 2. بنية قواعد بيانات مزدوجة ومرنة (Dual-Database Architecture)
- **Neon Postgres (Lakebase Postgres)**: جاهز للإنتاج عبر `@neondatabase/serverless` مع ملف الـ schema الكامل `neon_schema.sql`، والتخزين السحابي للصور عبر Cloudflare R2.
- **Node.js Native SQLite Fallback**: تشغيل محلي فوري بمجرد تشغيل المشروع دون الحاجة لضبط أي قاعدة بيانات سحابية بفضل وحدة `node:sqlite` المدمجة، مع تهيئة الجداول تلقائياً وإدراج منتجات تجريبية واقعية بكامل المواصفات.

### 3. نظام متقدم لحالات الأجهزة (جديد / كسر زيرو / مستعمل)
- فحص تفصيلي وشامل للأجهزة المستعملة وكسر الزيرو يعرض:
  - نسبة صحة البطارية (Battery Health %).
  - حالة الشاشة (أصلية 100% / بدون خدوش).
  - حالة الفريم والإطار الخارجي والظهر.
  - تاريخ الصيانة وفتح الجهاز.
  - توفر الكرتونة الأصلية والشاحن.
  - مدة ونوع الضمان.

### 4. نظام الألوان والمخزون المستقل لكل لون (Color & Inventory System)
- جدول ألوان موحد يدعم 15 لوناً عربياً مع كود الـ Hex الخاص بكل لون.
- إمكانية تحديد كمية مخزون مستقلة لكل لون على حدة لكل منتج.

### 5. نظام رفع وإدارة صور احترافي (Multi-Image Upload)
- إمكانية رفع حتى 10 صور عالية الدقة لكل منتج عبر السحب والإفلات أو التحديد المتعدد.
- تخزين الصور على Cloudflare R2 مع fallback تلقائي إلى مجلد `public/uploads`.
- إمكانية ترتيب الصور، تحديد أي صورة كغلاف رئيسي (Cover)، وحذف الصور نهائياً من الخادم.

### 6. سلة الشراء وتكامل الدفع والواتساب (Checkout & WhatsApp VIP Ordering)
- سلة تسوق تفاعلية مع شريط تقدم للشحن المجاني.
- إتمام الطلب باختيار المحافظة المصرية (مع حساب مصاريف الشحن ومدة التوصيل تلقائياً لكل محافظة).
- خيارات دفع متعددة: الدفع عند الاستلام (COD)، فودافون كاش مع رمز QR، وانستاباي (InstaPay) مع رمز QR.
- توليد كود مرجعي فريد لكل طلب مثل `#MOB-2026-XXXXX` وتجهيز رسالة واتساب منسقة بضغطة زر لمتابعة الطلب مع العميل.

### 7. لوحة تحكم إدارية شاملة ومتقدمة (Admin Dashboard)
- **إدارة المتجر العامة (Store Settings Tab)**:
  - **الهوية البصرية والعلامة التجارية**: تعديل اسم المتجر، الوصف، الشعار (الوضع الفاتح والداكن)، والأيقونة المصغرة.
  - **السلايدر الترويجي (Hero Slider)**: إضافة وحذف وتعديل شرائح العرض الرئيسية وتحديد الروابط والنصوص والأزرار.
  - **العملة والموقع الجغرافي**: اختيار العملة (ج.م، $، ر.س، د.إ)، موضع الرمز، وتنسيق الأرقام.
  - **الشحن والتوصيل**: إدارة المحافظات والمدن، أسعار الشحن، مدة التوصيل، وحد الشحن المجاني مع إمكانية التفعيل والتعطيل لكل مدينة.
  - **وسائل الدفع**: تفعيل وتعطيل طرق الدفع (عند الاستلام، فودافون كاش، انستاباي)، وتحديث أرقام التحويل وأكواد الـ QR.
  - **منصات التواصل الاجتماعي وخدمة العملاء**: إدارة روابط وأرقام الواتساب، فيسبوك، إنستغرام، وتيك توك.
  - **تخصيص المظهر**: التحكم في الألوان الأساسية ونمط العرض.
- **إدارة المنتجات**: إضافة، تعديل، حذف، بحث، وفرز مع فورم ديناميكي ذكي يغير الحقول بحسب القسم المختار (موبايل، شاحن، سماعة).
- **إدارة الطلبات**: فلترة ومتابعة وتحديث الحالات فوراً (`قيد المراجعة`، `تم التأكيد`، `تم الشحن`، `تم التسليم`، `ملغي`).
- **إدارة الأقسام والبراندات**: تخصيص التصنيفات والعلامات التجارية المدعومة.

## 📁 هيكلية الأقسام بالمتجر (Product Categories)

1. **الموبايلات (Mobile Phones)**: آيفون، سامسونج، شاومي، أوبو، ريلمي، فيفو، هونر، إنفينيكس، تكنو، هواوي، وغيرها.
2. **التابلت (Tablets)**: آيباد، سامسونج تاب، لينوفو، هواوي، وتابلت أندرويد أخرى.
3. **السماعات (Headphones)**: سماعات بلوتوث، إيربودز، سماعات سلكية، سماعات رأس، وسماعات ألعاب.
4. **الجرابات ووسائل الحماية (Cases & Protection)**: جرابات موبايل، جرابات تابلت، اسكرينات حماية، وحماية عدسات.
5. **الشواحن والكابلات (Chargers & Cables)**: شواحن سريعة، شواحن لاسلكية، كابلات شحن، باور بانك، وشواحن سيارات.
6. **الساعات الذكية (Smart Watches)**: ساعات أبل، ساعات سامسونج، أساور لياقة، وإكسسوارات ساعات.
7. **إكسسوارات أخرى (Other Accessories)**: حوامل هواتف، حوامل سيارات، كروت ذاكرة، ومحولات ووصلات OTG.

## 🚀 التشغيل والتثبيت (Getting Started)

### المتطلبات الأساسية
- Node.js إصدار `18.17.0` أو أحدث (يُفضل Node.js 20+ أو Node.js 22+ للاستفادة الكاملة من `node:sqlite`).
- npm أو pnpm أو yarn.

### 1. تثبيت الحزم
```bash
cd mobile-store
npm install
```

### 2. إعداد المتغيرات البيئية (اختياري)
قم بنسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```
> **ملاحظة هامة:** إذا لم تقم بإدخال `DATABASE_URL` الخاصة بـ Neon، سيعمل المتجر تلقائياً بنظام الـ SQLite المحلي المدمج في ملف `mobile_store.db`.

### 3. تشغيل خادم التطوير
يمكنك تشغيل بيئة التطوير السريعة (Vinext / Vite):
```bash
npm run dev
```
أو التشغيل التقليدي لـ Next.js:
```bash
npm run dev:next
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

### 4. بناء المشروع للإنتاج
```bash
# البناء والتشغيل عبر Vite / Vinext:
npm run build
npm run preview

# أو البناء والتشغيل عبر Next.js:
npm run build:next
npm run start:next
```

### 5. النشر على Cloudflare Workers (اختياري)
المشروع مهيأ ومزود بـ `@vinext/cloudflare` للنشر الفوري:
```bash
npm run deploy
```

## 🗄️ إعداد Neon Postgres (للبيئة السحابية)

1. سجّل الدخول إلى Neon باستخدام `neon login` ثم نفّذ `neon deploy` لسحب `DATABASE_URL` و `DATABASE_URL_UNPOOLED` إلى `.env.local`.
2. في حال إنشاء قاعدة بيانات جديدة فارغة، نفّذ محتوى الملف `neon_schema.sql` عبر Neon SQL Editor أو `psql` لإنشاء الجداول والبيانات الأولية.
3. للنشر على Cloudflare Workers، أضف `DATABASE_URL` كـ Secret في إعدادات الـ Worker.
