# فون زون | PhoneZone — متجر إلكتروني متكامل للهواتف الذكية والإلكترونيات

منصة تجارة إلكترونية عصرية متخصصة في بيع الهواتف الذكية، الأجهزة اللوحية، الساعات الذكية، الشواحن، الإكسسوارات ووسائل الحماية، مبنية بأحدث معايير **Next.js 16 (App Router)** و **React 19** ومصممة بالكامل باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL).

---

## 🌟 مميزات المشروع الرئيسية

### 1. تجربة مستخدم عربية فاخرة (Luxury Dark Theme + RTL)
- واجهة كاملة باللغة العربية بخط **Almarai** من Google Fonts وتنسيق كامل للعملات بالجنيه المصري (`ج.م`).
- هوية بصرية مقتبسة ومطورة من التصميم الفاخر (Dark Emerald/Lime Aesthetic) مع شريط عاجل متحرك (Marquee Ticker)، بطاقات عروض Bento Grid، ومؤقت تنازلي لعروض اليوم المحدودة.

### 2. بنية قواعد بيانات مزدوجة ومرنة (Dual-Database Architecture)
- **Supabase Cloud (PostgreSQL)**: جاهز للإنتاج مع ملف الميجريشن الكامل `supabase_schema.sql`، وسياسات أمان Row Level Security (RLS)، والتخزين السحابي للصور في باكت `mobiles`.
- **Node.js Native SQLite Fallback**: تشغيل محلي فوري بمجرد تشغيل المشروع دون الحاجة لضبط أي قاعدة بيانات سحابية بفضل وحدة `node:sqlite` المدمجة، مع تهيئة الجداول تلقائياً وإدراج منتجات تجريبية واقعية بكامل المواصفات.

### 3. نظام متقدم لحالات الأجهزة (جديد / كسر زيرو / مستعمل)
- فحص تفصيلي للأجهزة المستعملة وكسر الزيرو يعرض:
  - نسبة صحة البطارية (Battery Health %).
  - حالة الشاشة (أصلية 100% / بدون خدوش).
  - حالة الفريم والإطار الخارجي والظهر.
  - تاريخ الصيانة وفتح الجهاز.
  - توفر الكرتونة الأصلية والشاحن.
  - مدة ونوع الضمان.

### 4. نظام الألوان والمخزون المستقل لكل لون (Color & Inventory System)
- جدول ألوان موحد يدعم 15 لوناً عربياً مع كود الـ Hex الخاص بكل لون.
- إمكانية تحديد كمية مخزون مستقلة لكل لون على حدة لكل منتج.

### 5. نظام رفع وإدارة صور احترافي (Multi-Image Upload)
- إمكانية رفع حتى 10 صور عالية الدقة لكل منتج عبر السحب أو التحديد المتعدد.
- تخزين الصور على Supabase Storage مع fallback تلقائي إلى مجلد `public/uploads`.
- إمكانية ترتيب الصور، تحديد أي صورة كغلاف رئيسي (Cover)، وحذف الصور نهائياً من الخادم.

### 6. سلة الشراء وتكامل الواتساب (WhatsApp VIP Ordering)
- سلة تسوق تفاعلية مع شريط تقدم للشحن المجاني (أكثر من 3,000 ج.م).
- إتمام الطلب باختيار المحافظة المصرية (مع حساب مصاريف الشحن تلقائياً لكل محافظة).
- توليد كود مرجعي فريد لكل طلب مثل `#MOB-2026-XXXXX` وتجهيز رسالة واتساب منسقة بضغطة زر لمتابعة الطلب مع العميل.

### 7. لوحة تحكم إدارية متكاملة (Admin Dashboard)
- متابعة إحصائيات المبيعات، إجمالي الطلبات، والطلبات المعلقة.
- إدارة المنتجات (إضافة، تعديل، حذف) مع فورم ديناميكي ذكي يغير الحقول المطلوبة بحسب القسم المختار (موبايل، شاحن، سماعة).
- إدارة الطلبات مع تحديث الحالات فوراً (`قيد المراجعة`، `تم التأكيد`، `تم الشحن`، `تم التسليم`، `ملغي`).
- إدارة الأقسام والتصنيفات والبراندات (Brands).

## 📁 هيكلية الأقسام بالمتجر (Product Categories)

1. **الموبايلات (Mobile Phones)**: آيفون، سامسونج، شاومي، أوبو، ريلمي، فيفو، هونر، إنفينيكس، تكنو، هواوي.
2. **التابلت (Tablets)**: آيباد، سامسونج تاب، لينوفو، هواوي، تابلت أندرويد أخرى.
3. **السماعات (Headphones)**: سماعات بلوتوث، إيربودز، سماعات سلكية، سماعات رأس، سماعات ألعاب.
4. **الجرابات ووسائل الحماية (Cases & Protection)**: جرابات موبايل، جرابات تابلت، اسكرينات حماية، حماية عدسات.
5. **الشواحن والكابلات (Chargers & Cables)**: شواحن سريعة، شواحن لاسلكية، كابلات شحن، باور بانك، شواحن سيارات.
6. **الساعات الذكية (Smart Watches)**: ساعات أبل، ساعات سامسونج، أساور لياقة، إكسسوارات ساعات.
7. **إكسسوارات أخرى (Other Accessories)**: حوامل هواتف، حوامل سيارات، كروت ذاكرة، محولات ووصلات OTG.

## 🚀 التشغيل والتثبيت (Getting Started)

### المتطلبات الأساسية
- Node.js إصدار `18.17.0` أو أحدث (يُفضل Node.js 20+ أو Node.js 22+ للاستفادة الكاملة من `node:sqlite`).
- npm أو yarn أو pnpm.

### 1. تثبيت الحزم
```bash
cd mobile-store
npm install
```

### 2. إعداد المتغيرات البيئية (اختياري)
قم بنسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```
> **ملاحظة هامة:** إذا لم تقم بإدخال مفاتيح Supabase، سيعمل المتجر تلقائياً وبكفاءة 100% بنظام الـ SQLite المحلي المدمج في ملف `mobile_store.db`.

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

### 4. بناء المشروع للإنتاج
```bash
npm run build
npm start
```

## 🗄️ إعداد Supabase (للبيئة السحابية)

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. من لوحة تحكم Supabase، ادخل على **SQL Editor**.
3. افتح الملف `supabase_schema.sql` وانسخ محتواه والصقه داخل SQL Editor ثم اضغط **Run**.
4. ادخل على **Storage** وأنشئ باكت باسم `mobiles` واجعله **Public**.
5. انسخ رابط المشروع ومفتاح `anon key` و `service_role key` وضعهم في ملف `.env.local`.
